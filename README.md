# CChess

SDL2 chess project for CLion.

## Project Structure

- `src/app` - application loop and high-level game orchestration
- `src/chess/board` - board and field classes
- `src/chess/model` - shared chess data and teams
- `src/chess/moves` - move and move-set classes
- `src/chess/pieces` - chess piece base class and concrete pieces
- `src/ui` - UI widgets and screens
- `assets` - fonts, piece sprites, and other runtime assets
